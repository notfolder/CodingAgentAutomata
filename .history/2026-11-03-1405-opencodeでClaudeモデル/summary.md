# opencode で Claude のモデルを使えるようにする（PR #11 取り込み・PR #12 作成）

## 概要
opencode から LiteLLM 経由で Claude のモデルを呼べるようにし（PR #11、main に取り込み済み）、本番のプロバイダ名の無いモデル名にも対応した（PR #12、レビュー待ち）。

## やったこと

- **依頼**: opencode で Claude のモデルを使えるようにする。ブランチ `feature/opencode-claude-model` を切り、isdd の変更フロー（変更要件 → 外部連携の事前確認・調査 → 変更設計 → 実装 → 実装後の逆引き整合）で進めた。
- **1 回目の変更**（`.history/20261102-opencode-claude-model/`、PR #11、main の `2b90edc` で取り込み済み）
  - opencode は組み込みの `anthropic` プロバイダを使う。`OPENCODE_CONFIG_CONTENT` に、LiteLLM の URL + `/v1` と Virtual Key（`apiKey`）、`small_model`（タイトル用）を入れる。CLI アダプタ設定（DB）は変えていない。
  - 外部連携の調査（`external/litellm/docs/`）: 本物の Anthropic で Opus 5.5・Haiku 4.5 を、Anthropic 形式と OpenAI 互換の両方の呼び方で試した。どちらでもプロンプトのキャッシュが効いた。ユーザーの判断で Anthropic 形式を採用。
  - テスト用の `litellm/config.yml` に `drop_params: true` を入れた。モック LLM が推論の強さ（reasoning.effort）を拒むため。
  - `scripts/test_setup.sh` で LiteLLM を毎回作り直すようにした。設定ファイルを 1 ファイルだけ差し込んでいるため、置き換えても動いているコンテナに反映されない。
  - E2E に T-35 を足した。
- **2 回目の変更**（`.history/20261103-opencode-model-name-rule/`、PR #12、レビュー待ち）
  - 判定の決まり: `/` があれば前をプロバイダとする。`/` が無いときは、`claude-` で始まれば `anthropic`、それ以外は `openai` とする。opencode には常に「プロバイダ/モデル」の形で渡す。
  - OpenAI のプロバイダ名の無い名前（opencode が受け付けず止まっていた）も、同じ判定で直った。
  - T-35 はプロバイダ名を付けない名前で確かめる。
- **確認**
  - 単体テスト 51 件が通過。
  - 2 回目の変更の後、モック・模擬プロキシの通し確認が通過（Playwright 63 件通過・2 件スキップ、Zscaler の E2E 11 件通過）。
  - 本物の言語モデルでは 1 回目の変更の後に流し、T-31・T-32・T-35 が通過。T-34 はテストの確認が早すぎて失敗した。2 回目の変更の後は流していない（ユーザーの判断）。
  - isdd のチェックはすべて 0 件。
- **事故と対処**
  - Anthropic の API キーの値を、ツールの出力に一度出してしまった（BSD の sed で伏せ字が効かなかった）。ユーザーに報告した。以後は値を名前と長さだけで確かめ、コミット・PR の前に値が混じっていないか照合している。このメモと `session.md` には値は入っていない（照合済み）。
  - 実 LLM の確認で、既存のテストユーザーのデフォルトモデルが書き換わらず、Claude Code の MR タスク 6 件が Haiku ではなく Opus で動いた。
  - 2 回目の push の前に、PR #11 がすでに取り込まれていたことに気づかず、取り込み済みの PR #11 の本文を書き換えた。本文は元に戻し、2 回目の変更は PR #12 として出し直した。

## 決定事項

- 本番の LiteLLM のモデル名には「プロバイダ名/」が付かない。そのため、名前から判定する（`claude-` で始まれば Claude）。ユーザーの理由:「本番環境ではプロバイダ名/モデルというルールが無い」。
- 呼び方は Anthropic 形式（`/v1/messages`）にする。
- 外部連携のラッパー（`external/litellm/src/`）は作らない。
- 依存の無い問いは番号を付けてまとめて聞く。
- キーの値を出力に出さない。
